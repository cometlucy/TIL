  | 접두어 | 의미 | 예시 |

  | A | Actor를 상속하는 클래스 | APlayerCharacter |

  | F | 일반 구조체(Struct) | FPlayerData |
  | E | Enum | EWeaponType |

  | T | Template 계열 | TArray, Tmap |

  | BP_ | Blueprint | BP_Player |
  | SM_ | Static Mesh | SM_Door |
  | M_ | Material | M_Wood |
  | MI_ | Material Instance | MI_Wood |
  | T_ | Texture | T_Door |
  | WBP_ | Widget Blueprint | WBP_MainMenu |
  | ABP_ | Animation Blueprint | ABP_Enemy |
