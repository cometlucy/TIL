| 개념 | 기억해야 할 내용 |
|---|---|
| `&x` | 변수 `x`의 메모리 주소 |
| `int* p` | 정수 객체를 가리키는 포인터 선언 |
| `*p` | 포인터가 가리키는 객체에 접근 |
| `p = &y` | 포인터가 가리키는 대상을 `y`로 변경 |
| `*p = 25` | 포인터가 가리키는 객체의 값을 25로 변경 |
| `int& r = y` | 참조자 `r`을 `y`에 연결 |
| `r = x` | `x`의 값을 `r`의 참조 대상인 객체에 대입 |

- 포인터와 참조자

- 스택 메모리와 힙 메모리의 차이 : 스택 메모리는 함수 호출과 지역 변수의 수명을 관리하는 데 사용되며,
호출된 함수를 벗어나면 수명은 끝이 난다. 반면에 힙은 동적 메모리 영역으로, 동적으로 생성한 객체를 저장하는 데 사용되며, 함수가 종료된다고 종료되지 않는다.
new와 delete를 사용하여 직접 해제하거나 스마트 포인터를 써야한다.
- 댕글링 포인터 : delete p; 를 해서 객체의 수명은 끝났지만 포인터 변수 p 자체는 사라지지 않아 해제된 객체의 주소가 여전히 남아있는 포인터.
- 동적 메모리 할당 : 프로그램 실행 중에 필요한 메모리를 확보하여 객체를 생성하는 것.
