## 배운 것

```
#include <iostream>
using namespace std;

int main()
{
    int arr[7] = {10, 20, 30, 40, 50, 60, 70};
    int target = 60;

    int left = 0;
    int right = 6;

    while (left <= right)
    {
        int mid = (left + right) / 2;

        if (arr[mid] == target)
        {
            cout << "찾은 인덱스: " << mid << endl;
            break;
        }
        else if (arr[mid] < target)
        {
            left = mid + 1;
        }
        else
        {
            right = mid - 1;
        }
    }

    return 0;
}
```

- 현재 탐색 범위의 왼쪽 인덱스와 오른쪽 인덱스를 변수로 잡고 그 가운데 인덱스를 mid 로 잡아서 탐색
- mid의 인덱스가 가리키는 값이 타겟보다 큰지 작은지를 판별해 왼쪽 혹은 오른쪽 변수를 변경한다.

| 비교 항목 | 선형 탐색 | 이진 탐색 |
|---|---|---|
| 방식 | 처음부터 하나씩 확인 | 가운데를 기준으로 범위를 절반씩 줄임 |
| 정렬 필요 여부 | 필요 없음 | 일반적인 배열 탐색에서는 필요함 |
| 최악의 시간 복잡도 | `O(N)` | `O(log N)` |
| 구현 난이도 | 쉬움 | 상대적으로 조금 더 복잡함 |
| 적합한 상황 | 데이터가 적거나 정렬되지 않은 경우 | 정렬된 데이터에서 빠르게 찾는 경우 |

- 데이터가 정렬되어있고 오름차순인지 내림차순인지도 중요하다.
- 시간 복잡도는 선형 탐색의 최선의 경우는 O(1)도 가능하다. 한번만에 값을 찾은 경우. 그치만 최악의 시간 복잡도를 보통 생각한다.

```
int FindNumber(int arr[], int size, int target)
{
    for (int i = 0; i < size; i++)
    {
        if (arr[i] == target)
        {
            return i;
        }
    }

    return -1;
}

int main()
{
    int arr[5] = {7, 14, 21, 28, 35};

    cout << FindNumber(arr, 5, 28) << endl;

    return 0;
}
```

- 이 코드의 출력 값은 28의 인덱스 값인 3이다.  `return -1` 은 반복문이 끝날 때까지 값을 못 찾았을 때만 실행된다. 중간에 -1이 리턴되는 것이 아니다.
