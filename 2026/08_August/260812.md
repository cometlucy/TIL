# 2026-08-12 TIL

## 오늘 한 것
- 수업에서 새로운 프로젝트를 배우기 시작했다. FPS 만들기 프로젝트이다.
- 수업이 끝나고 팀플 회의를 진행했다. 드디어 우리 팀플의 프로젝트 파일을 만들고 소스트리를 이용해서 서로 주고받는 연습을 했다.

## 배운 것
- 언리얼 프로젝트 폴더 내부 파일에 대해 배웠다.
  - FPS.uproject : 언리얼 프로젝트를 실행하는 파일
  - FPS.sln : Visual Studio에서 C++ 프로젝트를 여는 파일
  - Source : C++ 게임 코드
  - Content : 게임 에셋
  - Config : 프로젝트 설정
  - Binaries : 빌드 결과물
  - Intermediate : 빌드 중간 파일
  - DerivedDataCache : 에셋과 쉐이더 캐시
  - Saved : 로그와 자동 저장 데이터
  - .vs : Visual Studio 작업 데이터
- 이 중 문제가 발생하면 Config / Content / Source / .uproject 를 냅두고 나머지는 다 삭제한 후 리빌드 하면 대부분 해결된다.
- 빌드
  - Ctrl +  B: 빌드.
  - F5: 빌드 및 실행
  - Shift + F5: 실행 중인 언리얼 에디터 종료.
  - Ctrl + Shift + F5: 실행 중인 언리얼 에디터 종료 후 빌드 및 실행.
- 소스(C++) 파일을 삭제하려면, 언리얼 에디터에서는 할 수 없고 비주얼스튜디오에서 삭제를 한 후, 폴더에서도 삭제를 또 해줘야 한다.

## 느낀 점
- 나는 Ctrl + F5를 많이 쓰는데 오늘 배운 내용엔 없었다. 오류가 자주 나던 이유가 이거였을 수도 있다 생각이 들었다
- 왜냐하면 오늘 수업때도 Ctrl + F5하니까 오류 나던 게 F5하니까 오류가 안났다!
- 좀 더 공부하고 익숙해지도록 노력해야겠다고 생각했다.
- 소스 파일을 만드는 건 정말 많이 해봤지만, 삭제하는 걸 배운 건 처음인 거 같다. 많이 쓸지는 모르겠지만 기억해 놔야겠다.
- 소스트리를 이용해서 깃으로 파일 주고 받는 게 수업에서 배울 때는 되게 어렵고 걱정이 많이 됐는데, 막상 실제로 해보니 할 만 하기도 하고 잘 되는 게 너무 신기했다!
