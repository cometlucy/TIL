## 배운 것
<img width="653" height="470" alt="image" src="https://github.com/user-attachments/assets/3943adaa-12a8-4bee-a766-43251eaedc90" />


- 언리얼 엔진에서 Actor 하나가 생성되고 사라질 때 어떤 함수가 어떤 순서로 호출되는지 확인하는 실습이었다.
- 생성 :액터가 메모리에 만들어지는 단계
- Constructor : 생성자(Constructor)가 실행되는 단계
- OnConstruction : 그 Actor를 배치하거나 값을 바꿨을 때 실제 모양/설정을 다시 적용하는 단계
- PostInitializeComponents : 컴포넌트들이 초기화된 다음 호출되는 단계
- BeginPlay : 실제 플레이가 시작되는 단계
- Tick : 게임이 실행되는 동안 계속 호출되는 함수 -> 그래서 로그에 계속 찍혀나온다!
- EndPlay : 플레이를 끝내는 단계
- Destroyed : Actor가 삭제되는 단계

- 요약하자면 <br> `만들어짐 -> 초기화-> 게임 시작 -> 매 프레임 실행 -> 게임에서 나감 -> 삭제`

## 느낀 점
- 실습에서 자꾸 로그에 Constructor가 여러번 찍히는 상황이 나왔다. 정확한 이유를 찾지 못해 다음에 질문을 드리거나 좀 더 찾아봐야겠다.
- 막연하게 게임 회사에 다니고 싶다라는 생각에서 레벨 디자인쪽을 하고 싶다는 마음이 생기기 시작했다. 내가 제작한 의도대로 플레이어들을 움직이게끔 하는 게 매력적인 요소라 생각든다.
- 팀플 말고 개인 프로젝트도 하나 시도해보고 싶은데, 이건 더더욱 맨땅에 헤딩 같은 느낌이 들어서 어렵다ㅜㅜ. 하더라도 팀플 진도를 따라가는 식으로 해야될 거 같다.
